# 运行边界

项目面向本地运行与多源 Agent 工程验证，默认使用 Synthetic Enterprise Retail。下面说明会影响调用、数据解释和部署的行为。

## 编排与会话

Planner 支持独立子任务并行与证据聚合。`depends_on` 是任务描述字段，当前不执行前序结果驱动后续输入的依赖调度。

LangGraph 使用进程内 MemorySaver：重启后 checkpoint 丢失，多 worker 不共享。数据库聊天历史独立持久化，不能据此完整恢复 Graph state。

## 响应、预算与取消

应用预算为 Router 60 秒、工具尝试 100 秒、整个 Agent 300 秒，底层数据库/检索客户端另有约束。外部模型与网络可能产生长尾；HTTP 200 需结合 `execution.status` 判断。耗时应保留失败与慢样本，方法见[评测说明](EVALUATION.md)。

Graph 同步调用在线程中执行。取消或预算到期后不再启动下游查询，但无法强制终止已在线程中进行的调用；底层仍受客户端自身超时限制。策略回退可能获得正确结果，也会增加成本和等待。

公共响应提供有限预览，不是原始结果全集。准确计数和聚合应由查询完成，不让模型从预览推断全部数据。

## 文件与文档身份

file-query success 表示摄取任务已提交；后台处理完成与可检索需另行确认，当前没有完整进度、失败查询和任务重试接口。

知识记录按 `(domain, dataset_id, source_id)` 标识。显式/fixed dataset_id 支持同一逻辑数据集更新；未知文件的内容哈希 ID 表示内容寻址，内容改变会得到新数据集。缺少业务主键时使用行号，行重排无法保证逻辑身份稳定。

原文分块与版本过滤保留来源范围，不自动解决跨段条件或版本冲突。HTTP 预览与回答上下文有独立容量预算，旧 `legacy_unverified` 内容不能视为已核验原文。

## 评测与回答解释

工程测试与合成演示不能代表真实业务分布。共享文档或包含已知开发问题的回归不等于盲测泛化；重排阈值不是答案概率。

有限事实、来源与引用检查不能覆盖所有否定、矛盾或额外声明。评分器仍可能漏识别未声明的等价表述。自行测量时应按输入和源码分别保存结果，方法见[评测说明](EVALUATION.md)。

## 部署与权限

Compose 端口默认绑定本机。当前使用短期 JWT Bearer 验证与 Session owner 隔离，身份来自签名 sub，客户端 user_id 不能覆盖身份；业务 SQL 使用独立只读账号、表/schema 白名单。尚无完整用户管理、RBAC、业务数据多租户隔离和行级访问控制。上传采用受控 file_id、归属验证、请求/文件分块限额及基本文件格式检查，未提供杀毒、完整内容安全扫描及租户配额。请在隔离环境使用演示凭据。

`/health` 表示进程存活，`/ready` 检查依赖与配置；二者都不验证每个模型请求的认证、每个数据集或完整事务。配置及服务升级见[部署说明](DEPLOYMENT.md)。

## 数据与分发

全部演示业务数据为合成数据。历史 Recipe 数据、词典与未确认授权资产不随公开仓库分发；少量旧别名和兼容代码不代表默认服务依赖。依赖声明为兼容范围，尚无完整环境锁定。组件许可见[第三方归属](../THIRD_PARTY_NOTICES.md)。
